# VidAudCont

Программа для Windows и macOS. Находит в записях разговоров всё, что нужно вырезать:
- начало и конец без речи;
- паузы длиннее 7 секунд;
- музыку;
- слишком тихую речь;
- короткие обрывки речи между вырезами.

Найденные таймкоды можно поправить. По отдельной кнопке программа вырезает эти куски **без потери качества**.

Она же проверяет, подходит ли запись: это должен быть разговор врача с пациентом (два голоса, реплики чередуются), на медицинскую тему, с британским акцентом. Лекции, закадровый голос и осмотры, где говорит один человек, отсеиваются.

**Пошаговая инструкция по подготовке и работе: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).**

## Установка

На странице **Releases** этого репозитория лежат три архива:

| Архив | Для чего |
|---|---|
| `VidAudCont-Windows.zip` | Windows 10/11 (64-бит) |
| `VidAudCont-Mac-AppleSilicon.zip` | Mac на процессорах M1–M4, macOS 12 и новее |
| `VidAudCont-Mac-Intel.zip` | Mac на процессоре Intel, macOS 11 и новее |

**Windows.** Распакуйте архив и запустите `VidAudCont\VidAudCont.exe`.
Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». У программы нет платной цифровой подписи, поэтому Windows так предупреждает.

**macOS.** Распакуйте архив и перенесите `VidAudCont.app` в «Программы». При первом запуске macOS скажет, что не может проверить разработчика: у программы нет платной подписи Apple. Разрешить запуск можно одним из способов:
- Откройте Системные настройки → Конфиденциальность и безопасность → внизу нажмите «Всё равно открыть».
- Или один раз выполните в Терминале `xattr -dr com.apple.quarantine /Applications/VidAudCont.app`.

Интернет программе не нужен: модели и ffmpeg уже внутри. Архив весит около 400–500 МБ.

## Как пользоваться

1. Перетащите файлы или папку в окно (или «Добавить файлы…»). Поддерживаются m4a, mp3, wav, flac, ogg, opus, aac, mp4, mov, mkv, webm, avi и другие форматы, которые читает ffmpeg.
2. Нажмите **«Анализировать все»**. Первый запуск дольше, потому что загружаются модели. Дальше 10-минутная запись обрабатывается примерно за 1–2 минуты.
3. Выберите файл в списке и посмотрите:
   - таймкоды в формате таблицы: `start-0:13, 3:10-3:17, 6:35-end` или `good`;
   - почему вырезается каждый кусок;
   - полосу времени, где синее — речь, а красное — вырезается;
   - акцент и тему.

   Таймкоды можно поправить прямо в поле. Кнопка «Копировать» копирует их для таблицы.
4. Нажмите **«Вырезать ✂»**. Рядом с исходным файлом появится `имя_cut.m4a`. Исходный файл не меняется.
5. «Экспорт в CSV…» сохраняет таблицу со всеми файлами, её можно открыть в Excel или Google Таблицах.

Результаты анализа сохраняются, так что после перезапуска программы они на месте. Незаконченный анализ после перезапуска продолжается сам.

## Работа с Google Таблицей

Программа сама находит, в какой строке таблицы лежит ссылка на каждый скачанный файл. Кнопка **«Вырезать все»** вырезает все файлы, называет результаты номером строки (`80.m4a`) и записывает таймкоды в колонку D.

### Подключение (один раз, ~3 минуты)
1. В программе: **«Таблица…» → «Скопировать код для Google»**.
2. В Google Таблице: **Расширения → Apps Script**. Удалите всё в редакторе, вставьте код (Ctrl+V) и нажмите «Сохранить» (значок дискеты).
3. Справа вверху **«Начать развёртывание» → «Новое развёртывание»**. Нажмите на шестерёнку и выберите тип **«Веб-приложение»**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все**.

   Нажмите «Начать развёртывание», затем «Предоставить доступ» и выберите свой аккаунт.
   Google предупредит, что «приложение не проверено». Это нормально: скрипт ваш собственный. Нажмите «Дополнительные настройки» → «Перейти на страницу…» → «Разрешить».
4. Скопируйте **«URL веб-приложения»** (оканчивается на `/exec`), вставьте его в программу и нажмите **«Проверить связь»**. Должно появиться «✓ Связь есть: …».

Скрипт работает только с этой таблицей и принимает запросы только с ключом из программы.

**Несколько компьютеров.** У скрипта один ключ, поэтому код в Apps Script ставится один раз. На остальных компьютерах: там, где связь есть, «Таблица…» → «Скопировать подключение»; на новом — «Вставить подключение». Работать можно одновременно; чтобы не делать одно и то же дважды, дайте компьютерам разные диапазоны строк.

### Как это работает
1. Добавьте скачанные файлы или папку. Программа прочитает ссылки из колонки C и найдёт для каждого файла его строку. Её можно узнать по:
   - названию видео. Годится и название на русском, в том виде, как его показал YouTube и сохранил загрузчик: даже с заменёнными знаками или обрезанное в конце;
   - номеру строки в начале имени (`80. …`);
   - id видео в имени.

   Номер строки появляется в колонке «Строка». Если программа строку не нашла, укажите её сами двойным щелчком.
2. **«Анализировать все»**.
3. Проверьте таймкоды. **«Вырезать все ✂»**:
   - вырезанные файлы сохранятся в папку `готово` рядом с исходными под именем `номер_строки.m4a`. Если вырезать нечего, файл просто копируется под новым именем;
   - таймкоды попадут в колонку D своей строки;
   - вырезаются только подходящие записи (колонка «Подходит»). У остальных в колонку E пишется причина: «НЕ РАЗГОВОР», «НЕ МЕДИЦИНСКАЯ ТЕМА», «АМЕРИКАНСКИЙ АКЦЕНТ» и т.п. (если в E пусто);
   - файлы, для которых строка ещё не найдена, программа не трогает. Они будут вырезаны при следующем нажатии, когда строка найдётся.

   Если Google не отвечает (например, ошибка 404), программа сама повторяет запрос несколько раз. Если таймкоды так и не записались, в статусе файла будет «таблица: ошибка». Нажмите «Вырезать все» ещё раз: программа допишет их в таблицу, не вырезая файлы заново.

   Таймкоды, которые вы уже вписали в таблицу вручную, программа не трогает, если в «Таблица…» не включена перезапись.
4. Кнопка **«В таблицу»** под таймкодами записывает в таблицу исправленные таймкоды одного файла.

## Расшифровки всех видео

Создайте в таблице отдельный лист и впишите его имя в «Таблица…» → «Лист для расшифровок». Программа расшифрует каждое видео, у которого нашлась строка (подходящее или нет, из красной строки тоже; вторая копия одного видео — нет), и запишет в строку с тем же номером, что в основном листе: A — ссылка, B — текст. Расшифровка идёт после анализа, по 4 файла одновременно, около 40 секунд на 10 минут записи (Whisper base.en). Ячейка Google Таблицы вмещает 50 000 знаков — это около 50 минут речи; текст длиннее продолжается в колонках C, D, …

## Повторы и красные строки

- **Повторы.** Если одно видео стоит в нескольких строках, программа обрабатывает его один раз, по первой строке. В список для скачивания повторы не попадают, даже если первая строка уже готова. В окне «4K Video Downloader+…» галочка «пометить повторы» пишет в колонку E остальных строк «ПОВТОР строки N». Строки программа не удаляет, иначе сдвинутся номера строк и имена файлов. Если одно видео скачалось дважды (`… (1).m4a`), второй файл программа не анализирует и не вырезает.
- **Красные строки.** Строку, которую не нужно обрабатывать, закрасьте красным (любым оттенком: заливка любой ячейки строки или цвет текста ссылки). Программа не даёт её ссылку на скачивание, не анализирует и не вырезает её файл. Для этого нужен код скрипта версии 2: если он старый, программа об этом скажет. Обновить: «Таблица…» → «Скопировать код для Google» → в Apps Script замените код и сохраните → «Начать развёртывание» → «Управление развёртываниями» → карандаш → Версия: «Новая версия» → «Развернуть». Адрес не изменится.

## Загрузка через 4K Video Downloader+

Кнопка **«4K Video Downloader+…»** решает две задачи: даёт ссылки для загрузки и настраивает папку, за которой следит программа.

1. Выберите диапазон строк таблицы (например, 80–491). Строки, где в колонке D уже есть таймкоды, и видео, файлы которых уже есть в программе, пропускаются. Если одно видео встречается в нескольких строках, ссылка попадает в список один раз.
2. Укажите **папку загрузок** и оставьте галочки «следить за папкой» и «сразу анализировать».
3. Нажмите **«Скопировать ссылки»**, затем OK. В ссылках нет хвостов `&list=…`, чтобы не скачивались целые плейлисты.
4. В 4K Video Downloader+ включите **Умный режим** (значок лампочки): *Аудио*, формат *M4A*, та же папка. Нажмите **«Вставить ссылку»**: добавятся все ссылки сразу. Если добавились не все, копируйте частями, например по 50 строк.

«Файл → Импорт загрузок» в 4K Video Downloader+ для этого не подходит: он принимает только файлы экспорта самого 4K Video Downloader.

Каждый скачанный файл программа сама добавит в список, найдёт его строку в таблице и проанализирует. Недокачанные файлы она не трогает. Когда всё готово, нажмите «Вырезать все».

## Если программа закрылась сама

Программа ведёт журнал `vidaudcont.log` в папке своих настроек:
- Windows: `%APPDATA%\VidAudCont\VidAudCont`;
- macOS: `~/Library/Application Support/VidAudCont/VidAudCont`.

Если в прошлый раз она закрылась неожиданно, при следующем запуске она об этом сообщит и покажет этот файл. Пришлите его разработчику.

Анализ по умолчанию занимает половину потоков процессора (на Ryzen 7 3700X — 8 из 16), так компьютер меньше греется и остаётся отзывчивым. Число потоков можно поменять в «Настройках».

Эти потоки программа сама делит между несколькими файлами и анализирует их одновременно, каждый в отдельном процессе. На Ryzen 7 3700X это 4 файла по 2 потока. Так выходит примерно в полтора раза быстрее, чем по одному файлу, при той же нагрузке на процессор. Результаты от этого не меняются. Если один анализ аварийно завершится, ошибка будет только у этого файла, остальные продолжат обрабатываться.

## Почему качество не ухудшается

- **Сжатые форматы (m4a/AAC, mp3, opus, ogg, видео).** Программа ничего не перекодирует. Она копирует из исходника нужные куски как есть и склеивает их. После вырезания программа проверяет контрольные суммы: каждый аудио- и видеопакет результата — точная копия пакета из исходника. Если всё так, внизу появится «✓ Без перекодирования: … скопированы бит-в-бит». Граница выреза точна до одного аудиокадра, это около 0,02 секунды.
- **Форматы без потерь (wav, flac, alac).** Программа режет с точностью до отсчёта и сохраняет в тот же формат с той же разрядностью. Затем сравнивает звук результата с исходным: он должен совпасть до последнего отсчёта.
- **Видео.** Без перекодирования видео режется только по ключевым кадрам, поэтому каждый оставленный кусок немного расширяется до ближайших ключевых кадров. Программа покажет, на сколько секунд. Если нужен только звук, выберите «Только звук (точно)».

## Настройки (кнопка «Настройки…»)

| Настройка | По умолчанию |
|---|---|
| Вырезать паузы длиннее | 7 с |
| Начало/конец без речи | от 3 с |
| Музыка | от 2 с |
| Кусок речи между вырезами | короче 8 с — вырезается |
| Слишком тихая речь | тише −31 дБ и на 7 дБ тише остальной записи |
| Определять, разговор ли это | да |
| «Вырезать все» — только подходящие | да |
| Куда сохранять | рядом с исходным файлом (при работе с таблицей — папка `готово`) |

Значения по умолчанию подобраны по вашей ручной разметке строк 5–69 таблицы.

## Ограничения

- Тему программа определяет по словам из расшифровки. Клинические видео она узнаёт уверенно, а психотерапию часто помечает как «проверьте». Это подсказка, окончательное решение за вами.
- Разговор программа узнаёт по голосам (два разных голоса чередуются) и по речи: если говорит в основном один человек, но обращается к пациенту («посмотрите на палец», «сделайте вдох»), это осмотр, и он подходит. Лекция или закадровый голос без пациента — «НЕ РАЗГОВОР». Лекция со вставками разыгранных сцен может сойти за разговор. Спорные записи лучше проверить по колонке «Подходит» и расшифровке.
- Правило «слишком тихая речь» настроено по одному примеру (строка 18). Если оно режет лишнее, выключите его или поменяйте порог в настройках.

## Командная строка

```
VidAudCont --analyze file1.m4a file2.m4a              # напечатать таймкоды
VidAudCont --cut "start-0:13, 6:35-end" file.m4a      # вырезать
VidAudCont --selftest                                 # самопроверка
```

## Для разработчика

```
pip install -r requirements-build.txt
python scripts/fetch_models.py && python scripts/fetch_ffmpeg.py
python -m pytest tests
python -m vidaudcont                     # запуск из исходников
pyinstaller vidaudcont.spec --noconfirm  # сборка
```

Сборки для Windows и macOS делает GitHub Actions (`.github/workflows/build.yml`). Он запускает тесты, собирает программу и прогоняет самопроверку уже собранной программы. Тег `v*` публикует релиз.
Сторонние компоненты и их лицензии перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
