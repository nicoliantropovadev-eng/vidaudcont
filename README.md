# VidAudCont

Программа для Windows и macOS. Находит в записях разговоров всё, что нужно вырезать:
- начало и конец без речи;
- паузы длиннее 7 секунд;
- музыку;
- слишком тихую речь;
- короткие обрывки речи между вырезами.

Найденные таймкоды можно поправить. По отдельной кнопке программа вырезает эти куски **без потери качества**.

Заодно она подсказывает акцент (британский или нет) и тему (медицинская или нет).

## Установка

На странице **Releases** этого репозитория лежат три архива:

| Архив | Для чего |
|---|---|
| `VidAudCont-Windows.zip` | Windows 10/11 (64-бит) |
| `VidAudCont-Mac-AppleSilicon.zip` | Mac на процессорах M1–M4, macOS 12 и новее |
| `VidAudCont-Mac-Intel.zip` | Mac на процессоре Intel, macOS 11 и новее |

**Windows.** Распакуйте архив и запустите `VidAudCont\VidAudCont.exe`.
Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». У программы нет платной цифровой подписи, поэтому Windows так предупреждает.

**macOS.** Распакуйте архив и перенесите `VidAudCont.app` в «Программы». При первом запуске macOS скажет, что не может проверить разработчика: у программы нет платной подписи Apple. Разрешить запуск можно одним из способов:
- Откройте Системные настройки → Конфиденциальность и безопасность → внизу нажмите «Всё равно открыть».
- Или один раз выполните в Терминале `xattr -dr com.apple.quarantine /Applications/VidAudCont.app`.

Интернет программе не нужен: модели и ffmpeg уже внутри. Архив весит около 400–500 МБ.

## Как пользоваться

1. Перетащите файлы или папку в окно (или «Добавить файлы…»). Поддерживаются m4a, mp3, wav, flac, ogg, opus, aac, mp4, mov, mkv, webm, avi и другие форматы, которые читает ffmpeg.
2. Нажмите **«Анализировать все»**. Первый запуск дольше, потому что загружаются модели. Дальше 10-минутная запись обрабатывается примерно за 1–2 минуты.
3. Выберите файл в списке и посмотрите:
   - таймкоды в формате таблицы: `start-0:13, 3:10-3:17, 6:35-end` или `good`;
   - почему вырезается каждый кусок;
   - полосу времени, где синее — речь, а красное — вырезается;
   - акцент и тему.

   Таймкоды можно поправить прямо в поле. Кнопка «Копировать» копирует их для таблицы.
4. Нажмите **«Вырезать ✂»**. Рядом с исходным файлом появится `имя_cut.m4a`. Исходный файл не меняется.
5. «Экспорт в CSV…» сохраняет таблицу со всеми файлами, её можно открыть в Excel или Google Таблицах.

Результаты анализа сохраняются, так что после перезапуска программы они на месте.

## Почему качество не ухудшается

- **Сжатые форматы (m4a/AAC, mp3, opus, ogg, видео).** Программа ничего не перекодирует. Она копирует из исходника нужные куски как есть и склеивает их. После вырезания программа проверяет контрольные суммы: каждый аудио- и видеопакет результата — точная копия пакета из исходника. Если всё так, внизу появится «✓ Без перекодирования: … скопированы бит-в-бит». Граница выреза точна до одного аудиокадра, это около 0,02 секунды.
- **Форматы без потерь (wav, flac, alac).** Программа режет с точностью до отсчёта и сохраняет в тот же формат с той же разрядностью. Затем сравнивает звук результата с исходным: он должен совпасть до последнего отсчёта.
- **Видео.** Без перекодирования видео режется только по ключевым кадрам, поэтому каждый оставленный кусок немного расширяется до ближайших ключевых кадров. Программа покажет, на сколько секунд. Если нужен только звук, выберите «Только звук (точно)».

## Настройки (кнопка «Настройки…»)

| Настройка | По умолчанию |
|---|---|
| Вырезать паузы длиннее | 7 с |
| Начало/конец без речи | от 3 с |
| Музыка | от 2 с |
| Кусок речи между вырезами | короче 8 с — вырезается |
| Слишком тихая речь | тише −31 дБ и на 7 дБ тише остальной записи |
| Куда сохранять | рядом с исходным файлом |

Значения по умолчанию подобраны по вашей ручной разметке строк 5–69 таблицы.

## Ограничения

- Тему программа определяет по словам из расшифровки. Клинические видео она узнаёт уверенно, а психотерапию часто помечает как «проверьте». Это подсказка, окончательное решение за вами.
- Правило «слишком тихая речь» настроено по одному примеру (строка 18). Если оно режет лишнее, выключите его или поменяйте порог в настройках.

## Командная строка

```
VidAudCont --analyze file1.m4a file2.m4a              # напечатать таймкоды
VidAudCont --cut "start-0:13, 6:35-end" file.m4a      # вырезать
VidAudCont --selftest                                 # самопроверка
```

## Для разработчика

```
pip install -r requirements-build.txt
python scripts/fetch_models.py && python scripts/fetch_ffmpeg.py
python -m pytest tests
python -m vidaudcont                     # запуск из исходников
pyinstaller vidaudcont.spec --noconfirm  # сборка
```

Сборки для Windows и macOS делает GitHub Actions (`.github/workflows/build.yml`). Он запускает тесты, собирает программу и прогоняет самопроверку уже собранной программы. Тег `v*` публикует релиз.
Сторонние компоненты и их лицензии перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
